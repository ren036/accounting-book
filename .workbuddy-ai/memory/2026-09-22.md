## 主题色从墨绿换成开屏 logo 的墨黑 #111827

**背景**：项目原本 `primaryColor: 'teal'`（自定义墨绿阶 `#34745e` 系），
用户要求把主题色改成开屏 logo 的黑色（`public/icon.svg` / `.app-boot__mark` / PWA theme_color 用的 `#111827`）。
确认后的方案：主色换黑，绿色降级为语义色；深色模式下主色自动转为浅色。

**实现要点**

- `src/theme.ts`：新增 `inkLight` / `inkDark` 两套色阶 + `virtualColor({ name: 'ink', ... })`，
  `primaryColor: 'ink'`，`primaryShade: { light: 7, dark: 5 }`，并开启 `autoContrast: true`。
  保留 `teal` 色阶不动（`--mantine-color-success` 仍指向它，且收入语义色还在用）。
- `SegmentedControl` 去掉了 `defaultProps.color`：它内部用 `getContrastColor()` 算标签色，
  拿不到虚拟色的真实值，深色模式会变成浅底白字。改用 Mantine 默认指示块。
- `Progress` / `Switch` 默认色 `teal` → `ink`。
- `src/styles.css`：`--book-green` 重命名为 `--book-ink`（亮 `#111827` / 暗 `#d8e0ea`）；
  背景、表面、边框、阴影、账本渐变等带绿色倾向的中性色一并中性化；
  深色模式补 `--switch-thumb-bg: #111827`（Mantine 滑块默认白色，浅色轨道上对比不足）。
- `index.html` + `SettingsPage` + `vite.config.ts`：theme-color、开屏底色、PWA background_color 同步；
  深色模式下开屏 logo 反转为浅底深字（否则墨黑在深色背景上不可见）。
- 组件层：按钮、图标、导航高亮、分类选中、图表小标题、链接等**品牌/交互用途**的 `teal` → `ink`
  或 `var(--book-ink)`；**语义绿保持 teal**（收入、存入、预算正常态、目标已存够）。

**验证**：`npm run build` 通过；用 headless Chrome + CDP 截了首页/资金页/记账页的亮暗两套，
并直接读取解析后的 CSS 变量确认链路：
亮色 `--mantine-color-ink-filled` = `#111827`、`contrast` = `#fff`；
深色 `--mantine-color-ink-filled` = `#cbd5e1`、`contrast` = `#000`、`--switch-thumb-bg` = `#111827`。

**教训**：同一文件的多处 Edit 若放在同一个消息里并行下发，会互相覆盖写入（这次 SavingsPage 丢了 2 处改动）。
同文件的多处改动要串行执行，改完用 grep 复查。
